**LOCKED CANON** identifies owner constraints and accepted playable/visual foundations. **PROPOSED FULL-STORY DEVELOPMENT** identifies authored material awaiting deliberate adoption. Publishing a proposal preserves it as project documentation; it does not approve its runtime implementation.

v0.3 resolves D-01 (P-01 adopted) and supersedes D-02 (the motive stays deliberately open); D-03 to D-10 remain open. Runtime implementation must not silently convert proposals into canon, change the accepted proof endpoint, or invent missing plot. Cite the adopted decision and scene version before building. Later passes should deepen Window Hall, Warm Main before rupture, and only then confinement/betrayal; v0.2 does not author that scene.
