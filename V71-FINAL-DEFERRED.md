# Rizo Defense v71 — Intentionally Deferred

1. **Server-authoritative competitive records / anti-cheat.** Local signatures are not a replacement for a trusted backend.
2. **Live telemetry-driven balance.** Exact economy/packet tuning should use real play data instead of speculative over-adjustment.
3. **Bespoke illustrated terrain packs.** Current world differentiation uses authored CSS/world-space features plus existing art; custom environment sprites can deepen it later without changing geometry contracts.
4. **Per-asset optical anchor metadata / normalized mascot source canvases.** Useful for pixel-perfect accessory/body alignment across legacy variants.
5. **Additional world mechanics/content.** The architecture supports more mechanics without needing more UI/CSS patch layers; they are content scope, not rebuild blockers.
6. **Remote crash/performance telemetry.** Useful for post-release device reality but not required for the local rebuild.
