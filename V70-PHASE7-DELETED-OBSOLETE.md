# Rizo Defense v70 — Deleted / Superseded Battlefield Rules

Phase 7 removes or supersedes these visual contracts rather than layering fixes over them:

1. Generic landmark geometry/background that flattened authored world landmarks.
2. Legacy 67px main road fill and its disproportionately heavy surrounding treatment.
3. Selected-tower debug-ring responsibility on `.defense-tower.selected::after`.
4. Always-visible textual route marker character.
5. Visible development-style ENTRY/GATE capsules as normal battlefield architecture.
6. Uniform world-tree presentation across all six maps.
7. Uniform debug-like build-pocket treatment across all worlds.
8. Device-by-device tower sizing in favor of one bounded `--def-unit-scale` contract.

No new Defense `!important` override layer was introduced.
