# Rizo Portal — Shopify theme

This folder holds the Rizo Apparel Shopify theme (rizo.store). It is separate
from the Rizo.game PWA that lives at the repository root.

- `theme/` — the complete, upload-ready Shopify theme (Online Store 2.0).
  Zip the *contents* of this folder (so `layout/`, `sections/`, … sit at the
  zip root) or push it with `shopify theme push --path shopify/theme`.

Baseline: Rizo Portal v2.3 (accessibility pass).
