A little life, not a daily obligation

The game starts with an egg. Follow the origin, tap the egg to hatch, and give your Rizo a name. The Den’s four care actions are Feed, Play, Rest, and Clean.

Needs change while you’re away. Sleeping restores energy. Recovery and ordinary care remain available without advertising or a purchase. The House opens at Level 4; residents live passively until you swap one into the active Den.

Your raised Rizo is the one who enters Dungeon. Time actively spent in Dungeon holds care needs; time with the app hidden is time away.

Your pet lives in this browser

Progress saves locally on this device. Another browser, a private window, a new phone, or a different website address will not automatically have it. There is no cloud account in this release.

  1. Open Journal → More.
  2. Use Export Save before clearing website data or moving devices.
  3. Keep that file somewhere you can find it. Use Import Save in the other browser to bring it back.

Changing from play.rizo.store to rizo.world is also a change of browser storage location. Export from the old address before moving.

If a save is unreadable, the game can keep a recovery copy. Journal → More has recovery downloads when they exist. A “Rizo is open somewhere else” message means another tab saved: reload this tab rather than starting over.

Cache repair and save reset are different. Repair App Cache reloads game files. Reset erases your local timeline after confirmation. Export first.

Save files and Garden Codes can contain your chosen names, Keeper ID, and game history. Share them only where you mean to; bug reports normally don’t need a full save.

Playing on a phone or keyboard

Den & House: tap the actions or a resident. Food can be dragged onto Rizo or selected with the keyboard. The bottom navigation takes you to Den, Arcade, House, Closet, and Journal.

Dungeon: move with the on-screen direction pad, arrow keys, or WASD. Z / Space is the primary action (Flare, inspect, or warm); X / K is Tuck. Escape pauses. The on-screen keys show the same actions. SIT and GO are choices, not a friendship score.

Defense: read the route, select a defense, then place it. The run has pause, save, and bank choices. Training games give their controls on the shelf and in the run; P pauses a training game.

Touch controls and scrolling have different jobs. The website scrolls normally. Dungeon locks page scrolling only while its Field Unit is open, then restores it when you leave. Portrait and landscape both work; no rotation is required.

Make the noise and motion yours

Journal → More has separate sound and music controls, volume sliders, haptics, and Reduced Motion. The game also reads your device’s reduced-motion preference. Dungeon settings include Assist and text speed; Defense has presentation and readability settings.

Public pages support text zoom, visible keyboard focus, skip links, and ordinary screen-reader navigation. Game menus use buttons and text. Dungeon tells include shape as well as color; sound is not the only cue.

The action games include visual playfields and timed input. They are not currently fully playable using a screen reader alone. This is a limitation we want reported clearly, not hidden behind an accessibility badge.

On mobile, a tap is needed before browser audio begins. If nothing plays, check game volume, your device’s audio route, and the iPhone silent switch.

When the window won’t open

If loading stops, use Reload Clean. If old game files keep returning, use Repair App Cache & Reload. Neither is the save-reset button.

You can play in a browser without installing. Installation help is in Journal → More. On iPhone, use Safari → Share → Add to Home Screen. On Android, use the browser’s Install or Add to Home screen option.

Offline loading is available after the game files have been cached successfully. The public pages don’t install anything. Advertising and external websites require a network; no ads are enabled in this release.

Tell Rizo what happened

Use the Rizo contact page ↗. It opens the physical brand’s website and uses that site’s contact form. There is no separate World account to log into.

For a game bug, include the device, browser, game build from Journal → More, what you did, and what happened. Include a screenshot if helpful. Don’t post private data or a full save publicly.
